# Spare Parts — Astro Arena

The individual game built on top of the shared [FSChuang/game-engine](https://github.com/FSChuang/game-engine):
an Astro Party-inspired multiplayer arena. Up to four ships fly forward at constant speed in a fixed
walled arena (a central reactor and four barriers). Hit by a bullet, or touching a wall or obstacle,
and a ship explodes and respawns two seconds later with a second of invulnerability. Bullets are
stopped by walls. There is no wrap-around.

## Controls

| Key | Action |
|---|---|
| A / Left | rotate left |
| D / Right | rotate right |
| Space | shoot |
| F5 | start recording a replay |
| F6 | stop recording |
| F7 | play the replay back (only while your ship is alive) |
| P | pause |
| 1 / 2 / 3 | timeline scale (0.5x / 1x / 2x) |
| Tab | toggle the renderer's scaling mode |

(On a Mac laptop hold `fn` for F5–F7.) A replay is a local, in-memory review of your own ship and
bullets; other players never see it. Multiplayer is peer-to-peer: every client decides only whether
*its own* ship was hit, and announces Shoot, Death and Spawn events to the others.

## Run a multiplayer game

```bash
./bin/server        # one terminal
./bin/main          # one terminal per player (2-4)
```

The ship, bullet, explosion and wall artwork is original, generated by `Game/assets/generate_assets.py`
(a development tool; the game just loads the committed PNGs from an `assets` folder that CMake copies
next to the executable).

## Repository layout

- `Game/` — this game's code. Authoritative here; edit freely.
- `Engine/` — a synchronized, read-only mirror of `game-engine`'s `Engine/`.
  **Do not edit `Engine/` manually** — changes are overwritten automatically. To
  change engine behavior, make the change in `FSChuang/game-engine` instead; it
  syncs here automatically on every push to `game-engine`'s `main` branch (see
  `.github/workflows/sync-engine.yml`).

## Build & run

```bash
mkdir build && cd build
cmake ..
make
./bin/main
```

## Requirements

- CMake 3.16+
- A C++17 compiler
- SDL3  (`brew install sdl3` on macOS / `sudo apt install libsdl3-dev` on Ubuntu)
